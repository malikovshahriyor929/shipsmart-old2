# Milliy Dastur Admin Dashboard

## Overview
This is the admin dashboard for the Milliy Dastur, providing administrative controls and management capabilities for the platform.

## Features
- User management
- Content management
- Analytics and reporting
- Settings configuration

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- pnpm package manager

### Installation
```bash
pnpm install
```

### Development
```bash
pnpm dev
```

### Build
```bash
pnpm build
```

## Technologies
- Next.js
- React
- TypeScript
- Tailwind CSS
