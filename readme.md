# ShipSmart Admin

## Overview
ShipSmart Admin is a single-app admin dashboard template.

## Key Features
- Admin dashboard app in `apps/admin`
- Shared UI, types, validators, and helpers in `@shipsmart/core`
- Shared Tailwind and TypeScript configs in `@shipsmart/tailwind-config` and `@shipsmart/typescript-config`

## Commands

```bash
pnpm install
pnpm dev
pnpm build
pnpm start
```

## Workspace
Only the `admin` app is kept under `apps/`. Other role-specific apps were removed from this template.
